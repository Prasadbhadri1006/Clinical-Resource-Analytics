# Clinical Resource Analytics | SQL & Power BI

## Project Overview
The Clinical Resource Analytics project focuses on analyzing hospital operations, patient management, appointments, admissions, laboratory services, prescriptions, medical inventory, and billing data using SQL and Power BI.

The project involved designing and developing a structured hospital database using MySQL, performing SQL-based analysis, validating data, and building an interactive Power BI dashboard to support hospital operational insights and data-driven decision-making.

## Tools & Technologies
- MySQL
- SQL
- Power BI
- DAX
- Data Modeling
- Data Analysis & Visualization

## Database Design
Designed and implemented a relational database with 17 tables to manage hospital-related data, including:

- Departments
- Staff
- Patients
- Rooms
- Procedures
- Lab Tests
- Medicines
- Appointments
- Admissions
- Vitals
- Lab Orders
- Lab Order Items
- Prescriptions
- Prescription Items
- Patient Procedures
- Invoices
- Invoice Items

## SQL Analysis
Performed SQL analysis using:

- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate Functions
- INNER JOIN, LEFT JOIN, RIGHT JOIN
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Views
- Stored Procedures
- Data Validation

## Power BI Dashboard
Connected the hospital database to Power BI and developed interactive visualizations to analyze clinical and operational data, helping understand hospital performance and resource utilization.

## Project Objectives
- Analyze hospital appointment and admission trends.
- Understand department-wise workload.
- Analyze patient visits and demographics.
- Monitor laboratory test status.
- Analyze hospital billing and revenue.
- Monitor medicine stock and low-stock items.
- Understand room utilization and hospital resources.
- Support data-driven hospital operational decisions.
